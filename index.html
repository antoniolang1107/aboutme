02 Selected projects

PSPNet

Full-stack · ML platform · Team of 4

A web platform for a wildfire research grant. The public and research teams upload photos of plants and soil from before and after fires, and the images are classified by computer vision models.

Problem
Researchers needed one place to collect field images from volunteers and lab members, organize them into datasets, run classification models on them, and have experts check the labels.
My role
Built much of the Flask API and Vue frontend: browsing and downloading datasets, shared projects with email invites, a label-verification workflow that only principal investigators can use (JWT-protected), and each user's upload history.
Result
126 commits and about 3.9k lines over 5 months, the second-largest contribution on the team. The platform runs in Docker, and a Redis/RQ worker queue runs a YOLOv5 model exported to ONNX.

Ping Pong Palooza

Full-stack · Mobile

A mobile app for recording local ping pong matches and ranking players on a live Elo leaderboard.

Problem
Friendly rivalries had no record of who was actually winning.
Approach
An Expo / React Native app written in TypeScript, talking to a Flask API backed by PostgreSQL. Each recorded match updates both players' Elo ratings on the server, and rankings are computed in SQL with window functions.
Result
Working end to end: register players, record matches, and watch the leaderboard update. Includes typed request validation with Pydantic and structured logging.
  • TypeScript
  • React Native
  • Expo
  • Flask
  • PostgreSQL

Auction Scraper

Automation

A scheduled scraper that watches a local online auction site and emails me listings that match what I'm looking for.

Problem
Checking hundreds of auction lots by hand every week took too much time.
Approach
Selenium drives a headless Firefox through a JavaScript-heavy site. Searches are defined in JSON config files (keywords, categories, recipient), and a conductor script runs every search and sends an HTML digest through the Gmail API.
Result
I use it regularly. Adding a new search takes a few lines of config, not code.
  • Python
  • Selenium
  • Gmail API
  • OAuth
